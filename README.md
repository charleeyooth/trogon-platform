# TROGON Platform

### Global Mobile Connectivity Platform

TROGON is a digital connectivity product with mobile user experiences and an administrative platform for managing operations, users, wallets, payments, orders, plans, destinations, and rewards.

This repository is a **public portfolio showcase**. Proprietary source code, credentials, infrastructure details, and private business logic are not published here.

## Product Areas

- Users
- Wallet
- Payments
- Orders
- Plans
- Destinations
- Rewards

## Confirmed Admin Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Recharts
